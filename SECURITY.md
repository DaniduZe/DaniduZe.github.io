# Security Policy

## Supported Versions

Only the latest deployment on the `main` branch of `DaniduZe.github.io` is actively maintained and receives security updates.

## Reporting a Vulnerability

If you discover a security issue or vulnerability in this repository or live site (`https://daniduze.github.io/`), please report it responsibly rather than opening a public issue:

- **Email:** danidusennath@gmail.com
- **Subject:** `[Security] DaniduZe.github.io Vulnerability Report`

Please include a clear description of the issue, steps to reproduce, and potential impact. You can expect an acknowledgment within 48 hours.
